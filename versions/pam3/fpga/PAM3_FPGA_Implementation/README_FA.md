# تحویل پیاده‌سازی دیجیتال پتنت US11405248B2

این بسته، هسته دیجیتال پیوسته و قابل سنتز پتنت را تا خروجی نمادهای PAM3 در
کامپیوتر پیاده‌سازی می‌کند. دو کانال مستقل دارد، می‌تواند در هر کلاک یک یا
هشت نمونه ورودی بگیرد و حافظه آن با طول داده افزایش پیدا نمی‌کند.

**بخش انجام‌شده:** RTL کامل DC، تشخیص سطح از شیب، حذف ضربه، تشخیص لبه، دو
فیلتر لبه، تولید و فیلتر نقطه برداشت، برداشت نماد، بافر و بسته‌بندی دو کانال،
داوری خروجی، و برنامه خواندن خروجی. آستانه ثابت و آستانه تطبیقی با حساب صحیح
هر دو پیاده‌سازی و آزمایش شده‌اند. نسخه تطبیقی بازسازی مهندسی است؛ پتنت
معادله دقیق تغییر آستانه را منتشر نکرده است.

**وضعیت سخت‌افزار:** مدار دیجیتال با Yosys برای خانواده Xilinx 7-series
سنتز شده است. فایل‌های Vivado برای ساخت پروژه و بررسی زمان‌بندی همراه بسته
هستند. Vivado، برد واقعی، ADC و USB فیزیکی در این محیط اجرا نشده‌اند؛
بیت‌استریم برد و نتیجه تأیید سرعت ۸۰۰ MS/s جزو خروجی نیستند. برای این مرحله
باید برد و تراشه‌های واقعی مشخص شوند و زمان‌بندی روی همان سخت‌افزار تأیید شود.

## از کجا شروع کنم؟

۱. این فایل و `docs/INTERFACES.md` را بخوانید؛ ورودی هسته نمونه ADC هشت‌بیتی
است، نه سیم LVDS یا سیگنال آنالوگ.

۲. برای آزمایش دوباره، Python، NumPy، SciPy و Icarus Verilog را نصب کنید و
داخل پوشه همین بسته اجرا کنید:

```bash
python3 -m pip install -r requirements.txt
python3 verify_hdl.py
python3 verify_interfaces.py
```

۳. خروجی آماده نمونه را بدون FPGA در کامپیوتر بازخوانی کنید:

```bash
python3 host_decode.py results/example_host_records.bin \
  --csv results/example_decoded_symbols.csv \
  --summary results/example_decoded_summary.json
```

هر ردیف CSV شماره کانال، بازه دریافت، ترتیب نماد و مقدار منفی یک/صفر/مثبت یک
را دارد. این نمادها هنوز فریم Ethernet نیستند. فایل ورودی نمونه نیز در
`results/example_adc_input.txt` قرار دارد.

۴. برای باز کردن طرح در Vivado:

```bash
vivado -mode batch -source vivado/create_project.tcl \
  -tclargs xc7a200tfbg484-2 8 0 0
```

نام FPGA بالا فقط مثال است. باید با قطعه برد انتخابی جایگزین شود. اعداد
بعدی به‌ترتیب تعداد نمونه در کلاک، فعال بودن DC و فعال بودن آستانه تطبیقی هستند.
پروژه در `vivado/build/project` ساخته می‌شود.

۵. برای سنتز و بررسی قرارگیری و مسیریابی هسته در Vivado:

```bash
vivado -mode batch -source vivado/synth_ooc.tcl \
  -tclargs xc7a200tfbg484-2 8 0 0 1
```

گزارش WNS/TNS و مسیرهای بدون قید باید بررسی شوند. قید نمونه کلاک ۱۰۰ MHz
فقط هدف بررسی است. وجود این قید، به‌معنای دستیابی واقعی به ۸۰۰ MS/s نیست.
پین‌ها و رابط ADC/USB برد هنوز در این پروژه تعیین نشده‌اند.

## نتیجه آزمون و فایل‌های مهم

نتایج واقعی به‌صورت JSON و متن ثبت شده‌اند؛ گزارش PDF و صفحه HTML همین
اعداد را نمایش می‌دهند. ۱۶ اجرای RTL، هر هشت تنظیم اصلی را روی داده‌های
کوتاه، بلند، نویزی و مرز آستانه بررسی کرده‌اند. در آزمون‌های RTL مجموعاً
۷۳٬۲۰۶ نماد و ۸۳۰٬۶۴۰ پردازش نمونه با مرجع تطبیق داشتند. این تعداد شامل
تکرار داده‌ها برای تنظیم‌های مختلف و اجرای هسته و مسیر دوکاناله است.

| مسیر | کاربرد |
|---|---|
| `rtl/pam3_analyzer_core.sv` | هسته اصلی دوکاناله تا رکورد میزبان |
| `rtl/pam3_stream_core.sv` | هسته مستقل همراه اندیس دقیق نقطه برداشت |
| `rtl/pam3_capture_fifo.sv` | بافر تک‌کلاکی اختیاری با تشخیص سرریز |
| `host_decode.py` | تبدیل خروجی دودویی به نمادهای CSV |
| `reference/integer_model.py` | مرجع مستقل حساب صحیح و تطبیقی |
| `results/verification/validation.json` | نتایج کامل تطبیق RTL |
| `results/interfaces/validation.json` | آزمون بافر، ریست، ورودی نامعتبر و خواندن رکورد |
| `results/synthesis/` | گزارش و مدار سنتزشده با Yosys |
| `results/post_synthesis/` | آزمون مدار حاصل از سنتز |
| `vivado/` | اسکریپت پروژه، سنتز و قیدهای نمونه |
| `docs/PATENT_ASSUMPTIONS.md` | بخش‌های افشاشده و فرض‌های بازسازی |
| `docs/source_patent.pdf` | فایل کامل پتنت مبنا |

## تنظیم پیشنهادی برای شروع آزمایش

`LANES=8, DC_ENABLE=0, ADAPTIVE=0` مبنای ساده و قابل مقایسه با پتنت است.
DC خاموش همان حالت مجاز bypass در متن پتنت است. رابطه DC چاپ‌شده وقتی
فعال شود، نمونه اصلاح‌شده را به حداقل ۹۵ می‌رساند؛ در همان حال شرط سطح
منفی مقدار کمتر از ۹۵ می‌خواهد. این ابهام را پنهانی تغییر نداده‌ام: حالت
لفظی DC هم موجود و آزمایش شده و توضیح کامل در سند فرض‌ها آمده است.

برای اتصال واقعی، مراحل باقی‌مانده به‌ترتیب انتخاب مدار آنالوگ و ADC/برد،
رابط و هم‌زمان‌سازی ADC، تأیید زمان‌بندی، انتقال DMA/USB یا رابط انتخابی،
کالیبراسیون با سیگنال واقعی و در صورت نیاز پیاده‌سازی لایه PCS و Ethernet است.
سرریز بافر باید دریافت را نامعتبر کند و موجب شروع دوباره شود؛ ادامه دادن
روی نمونه‌های ناقص، خروجی قابل اعتماد ایجاد نمی‌کند.
