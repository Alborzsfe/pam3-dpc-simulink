# مدل Simulink مقایسهٔ هیسترزیس و PAM3

همان آزمایش قبلی، این بار به‌صورت مدل بلوکی: دو ورودی تمیز و نویزی، هیسترزیس و PAM3 اصلی، توان بار فرضی، Scope و ثبت خروجی‌ها.

## شروع

۱. **کل ZIP** را استخراج کنید؛ فایل SLX را به‌تنهایی جابه‌جا نکنید.

۲. در MATLAB وارد پوشهٔ Hysteresis_PAM3_Simulink شوید.

۳. برای ساخت، بازکردن و اجرای مدل بنویسید:

    START_SIMULINK_COMPARE

این دستور ابتدا مدل را با API خود Simulink می‌سازد و ذخیره می‌کند، بعد آن را باز و اجرا می‌کند. خروجی‌های واقعی مدل را با کد MATLAB قبلی نمونه‌به‌نمونه مقایسه می‌کند و سپس THD و ریپل را از خروجی ثبت‌شدهٔ مدل گزارش می‌دهد.

اگر فعلاً فقط می‌خواهید بلوک‌ها را ببینید و اجرا نکنید:

    OPEN_SIMULINK_MODEL

مدل در این مسیر قرار دارد:

    models/hysteresis_pam3_compare.slx

به MATLAB و Simulink نیاز دارید. مدل در حالت Normal اجرا می‌شود. Simscape، Signal Processing Toolbox، HDL Coder، کامپایلر C و Python برای اجرای شما لازم نیستند.

## داخل مدل چه می‌بینید؟

| بخش | کاری که انجام می‌دهد |
|---|---|
| Clean_ADC | سینوس تمیز، پس از تبدیل مشترک ADC |
| Noisy_ADC | همان سینوس با نویز گاوسی، پس از ADC |
| Clean_Test | مقایسهٔ دو بلوک با ورودی تمیز مشترک |
| Noisy_Test | مقایسهٔ دو بلوک با ورودی نویزی مشترک |
| Levels_Scope | خروجی هیسترزیس و PAM3؛ ترتیب بردار: هیسترزیس، سپس PAM3 |
| Power_Scope | توان فرضی همان دو خروجی؛ با همان ترتیب |
| Log | ثبت داده برای محاسبهٔ معیارها و بررسی صحت |

روی Clean_Test یا Noisy_Test دابل‌کلیک کنید. در هر کدام:

- مسیر بالا، کم‌کردن آفست ADC، بازگرداندن مقیاس و بلوک **Relay خود Simulink** برای هیسترزیس است.
- مسیر PAM3، همان نمونهٔ ADC را به **PAM3_Detector** می‌دهد.
- دو شاخهٔ پایین، سطح خروجی را به ولتاژ فرضی تبدیل می‌کنند و با بلوک‌های مربع و تقسیم بر مقاومت، توان را می‌سازند.

روی PAM3_Detector دابل‌کلیک کنید:

- Original_Decoder، گیرندهٔ اصلی موجود در فایل PAM3 شماست؛ به‌صورت Level-2 MATLAB S-function اجرا می‌شود.
- Demux، علامت اعتبار و مقدار نماد را جدا می‌کند.
- Switch و Unit Delay، **نگه‌داشتن آخرین نماد معتبر** را آشکارا پیاده می‌کنند. خروجی قبل از اولین نماد معتبر صفر است.
- تأخیر الگوریتم اصلی حفظ می‌شود.

الگوریتم داخلی گیرنده، شامل تشخیص شیب، آستانه‌ها، فیلتر و زمان‌بندی، در یک S-function اجرا می‌شود؛ آن مراحل به بلوک‌های مستقل تجزیه نشده‌اند. برای دیدن کد کامل:

    edit pam3_step
    edit pam3_sfun

هیچ خروجیِ ازپیش‌محاسبه‌شده‌ای به‌جای دو بلوک پخش نمی‌شود؛ فقط ورودی‌های مشترک از Workspace خوانده می‌شوند و تصمیم‌گیرها در زمان اجرای مدل محاسبه می‌کنند.

## تنظیمات

همهٔ تنظیمات آزمایش در comparison_config.m هستند:

- سینوس ۵۰ هرتز، نرخ نمونه‌برداری ۲۴ کیلوهرتز.
- نویز با SNR برابر ۲۰ دسی‌بل و بذر ثابت؛ هر دو بلوک همان تحقق نویز را می‌گیرند.
- آستانه‌های هیسترزیس ±۰٫۲ و خروجی ±۱؛ حالت اولیه −۱.
- PAM3 با همان آستانه‌های اصلی ۱۴۰، ۹۵، ۱۶۰ و ۸۰؛ تطبیق و تصحیح DC خاموش.
- هر سطح خروجی برابر یک ولت روی مقاومت فرضی یک اهم.
- حذف پنج دورهٔ شروع و اندازه‌گیری روی ۲۰ دورهٔ مشترک.

پس از تغییر تنظیمات، START_SIMULINK_COMPARE را دوباره اجرا کنید. این دستور مدل داخل بسته را از روی تعریف اصلی بازسازی می‌کند. اگر مدل باز، تغییرات ذخیره‌نشده داشته باشد، بازسازی متوقف می‌شود تا آن‌ها ناخواسته حذف نشوند. تغییرات دستیِ ذخیره‌شده نیز با بازسازی جایگزین می‌شوند؛ برای حفظ آن‌ها، مدل شخصی را با نام دیگری ذخیره کنید.

برای اجرای مجدد همان مدل از دکمهٔ Run نیز می‌توانید استفاده کنید و Scopeها را ببینید. تحلیل و گزارش کامل با START_SIMULINK_COMPARE انجام می‌شود.

## خروجی‌ها و آزمون تطبیق

پس از اجرای موفق، پوشهٔ results_simulink ساخته می‌شود:

| فایل | محتوا |
|---|---|
| summary.csv | چهار ردیف نتایج تمیز/نویزی و هیسترزیس/PAM3 |
| clean_comparison.png | نمودارهای حالت تمیز از خروجی مدل |
| noisy_comparison.png | نمودارهای حالت نویزی از خروجی مدل |
| comparison_result.mat | داده‌های ثبت‌شده و توان خروجی بلوک‌ها |
| waveforms.csv | داده‌های نمونه‌به‌نمونه |
| simulink_validation.mat | نتیجهٔ تطبیق اجرای واقعی مدل با مرجع MATLAB |
| run_info.txt | مشخصات اجرا و وضعیت اجرای Simulink |

آزمون، تعداد و زمان نمونه‌ها، ورودی ADC، هر دو خروجی، همهٔ ۱۸ مؤلفهٔ ردگیری PAM3 و محاسبهٔ توان را بررسی می‌کند. اختلاف‌ها بی‌صدا حذف، جابه‌جا یا اصلاح نمی‌شوند؛ محل اولین اختلاف گزارش می‌شود.

**THD و THD+N پس از اجرا و از دادهٔ ثبت‌شدهٔ مدل محاسبه می‌شوند؛ بلوک اندازه‌گیری آنلاین THD داخل مدل نداریم.** ریپل توان از خروجی بلوک‌های توان مدل اندازه‌گیری می‌شود.

پوشهٔ results_reference فقط نمونهٔ نتایج کد MATLAB قبلی است؛ نتیجهٔ اجرای جدید Simulink نیست. START_COMPARE همچنان آزمایش صرفاً MATLAB را اجرا می‌کند.

## معنی توان و محدودیت مقایسه

توان بر اساس فرض p=v²/R تعریف شده است. خروجی ±۱ هیسترزیس، روی بار یک اهم توان ثابت یک وات می‌دهد و ریپلش الزاماً صفر است. این نتیجه به‌تنهایی نشانهٔ برتری روش نیست. PAM3 خروجی صفر هم دارد و توانش می‌تواند صفر شود. توان متوسط دو خروجی یکسان نشده است.

نرخ زمانی PAM3 برای این آزمایش ساده تغییر مقیاس داده شده، ولی قواعد نمونه‌ایِ الگوریتم اصلی حفظ شده‌اند. این، آزمایش یک گیرندهٔ مخابراتی در نرخ اصلی یا اندازه‌گیری توان یک مدار واقعی نیست.

## وضعیت بررسی هنگام تحویل

در محیط تحویل MATLAB/Simulink موجود نیست. بنابراین **اجرای بومی موتور Simulink و بازشدن SLX در MATLAB اینجا تأیید نشده‌اند.**

فایل SLX همراه از نظر ساختار بسته، ارجاع‌های XML، بلوک‌ها و اتصال پورت‌ها بررسی شده است و پیش‌ساخته محسوب می‌شود. روش توصیه‌شده، OPEN_SIMULINK_MODEL یا START_SIMULINK_COMPARE است تا فایل با API رسمی، داخل خود MATLAB شما از نو ساخته و ذخیره شود.

کد محاسباتی و تحلیل داده در Octave بررسی می‌شود؛ این بررسی جای اجرای Simulink را نمی‌گیرد. آزمون تطبیق همراه فقط پس از اجرای واقعی روی MATLAB شما می‌تواند PASS اجرای Simulink بدهد.
